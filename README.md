# Horóscopo — Signos

Projeto pessoal desenvolvido por Guilherme Henrique Peterlini Tavares.

## Visão Geral

Aplicação em PHP que exibe informações sobre os signos do zodíaco.

## Estrutura do Repositório

| Arquivo | Descrição |
|---|---|
| `index.php` | Página principal |
| `show_zodiac_sign.php` | Lógica de exibição do signo |
| `signos.xml` | Base de dados dos signos em XML |
| `layouts/` | Layouts da aplicação |
| `assets/` | Recursos estáticos (imagens, CSS, etc.) |

## Como Usar

Rode em um servidor com suporte a PHP (ex: `php -S localhost:8000`) e acesse `index.php` no navegador.
